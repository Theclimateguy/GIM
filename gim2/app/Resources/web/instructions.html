Инструкции — как пользоваться GIM18

Практическое руководство по интерфейсу приложения — что где находится и как этим пользоваться. Архитектура и математика модели описаны на вкладке «Документация»; здесь — только «как нажать и что получится», включая всё, что добавилось в последнем обновлении: полный доступ ассистента к инструментам движка, сессии диалогов, трейс агента, переигрывание сценария в аналитических режимах и обновлённые «Чувствительность» / «Слабые сигналы».

Ассистент — основы

Естественно-языковой интерфейс к движку. Опишите сценарий или вопрос в поле внизу экрана и отправьте (кнопка со стрелкой или Enter). Без подключённой LLM ассистент распознаёт вопрос по ключевым словам и умеет запускать только «карту ответа» (архетипы/рычаги). С подключённой LLM (Ollama локально или ключ OpenAI-совместимого провайдера) ассистент получает доступ ко всем инструментам движка и может вести содержательный диалог — уточнять детали, объяснять механику, сравнивать сценарии.

Подключение LLM

Значок шестерёнки в правом верхнем углу вкладки — выбор провайдера: «Без LLM», «Локально (Ollama)» или «OpenAI-совместимый (по ключу)» (включая DeepSeek через Base URL). Кнопка «Проверить» тестирует соединение. Берите модель с поддержкой function calling / tools — без этого инструменты движка ассистенту недоступны.

Сессии диалогов

Каждый диалог с ассистентом — отдельная именованная сессия, полностью сохраняется на диск (переживает перезапуск приложения). Список сессий и раньше не было — раньше был один общий чат без истории.

Как пользоваться

  1. В боковом меню нажмите на пункт «Ассистент» — раскроется список сессий прямо под ним (как история сессий в Claude Code): текущая, все прошлые, кнопка «+ Новая сессия» сверху.
  2. Повторный клик по «Ассистент» сворачивает список.
  3. Клик по любой сессии в списке переключает на неё — весь диалог и посчитанные в нём результаты восстанавливаются.
  4. Правый клик по сессии → «Удалить сессию» (последнюю сессию удалить нельзя — вместо неё будет создана новая).

Заголовок сессии — дата и время создания (например «03.07 14:08»), без слов, для компактности списка.

Инструменты ассистента

При подключённой LLM ассистенту доступны все аналитические режимы движка, а не только «карта ответа» — раньше был доступен только первый инструмент из таблицы.

ИнструментКогда используетсяЧто возвращает
Карта ответа Новый стратегический вопрос «что если…», сценарий ещё не задан. Вердикт, дельты метрик, цепочка последствий по доменам, точка перелома, победители/проигравшие страны — карточка «Ситуационная комната».
Сценарий Быстрая проверка комбинации рычагов без карточки целиком. Графики отклонения (Δ) метрик от базы + картинка графика прямо в чате.
Ансамбль «Насколько неопределённа сама база» / без сценария. Веер неопределённости (медиана, 5–95%) по метрикам.
Доза-отклик «Сколько нужно рычага, чтобы это стало заметно» / линеен ли эффект. Кривая «сила рычага → итог» по сетке интенсивностей.
Чувствительность «От какого допущения сильнее всего зависит результат». Ранжирование параметров (μ*), в процентах от самого влиятельного. Можно наложить на уже посчитанный сценарий.
Слабые сигналы «Не приближается ли сценарий к срыву в другой режим». Аномалии Махаланобиса, структурные сдвиги по метрикам, тренд критического замедления (экспериментально).
Списки архетипов / рычагов Ассистент уточняет доступные типовые сценарии или рычаги. Текстовый список — служебный вызов, картой/графиком не отображается.

Для «Сценарий» / «Чувствительность» / «Слабые сигналы» тот же графический результат, что и в панелях Экспертного режима — ассистент вызывает ровно те же расчёты движка.

Как ассистент выбирает инструмент

Раньше ассистент почти всегда вызывал только «карту ответа» повторно, даже когда вопрос был явно про чувствительность или устойчивость. Теперь модель получает три уровня подсказки:

  • Активный сценарий. Если в сессии уже посчитан сценарий, приложение прямо сообщает модели его точную формулу (рычаги и магнитуды) — не нужно пересчитывать заново, чтобы задать уточняющий вопрос про него же.
  • Таблица маршрутизации. Явное соответствие «формулировка вопроса → инструмент» в системной инструкции модели (например: «что сильнее всего влияет» → Чувствительность; «устойчив ли сценарий / риск срыва» → Слабые сигналы).
  • Жёсткая подсказка (Слой 3). При явных маркерах в вопросе («чувствительность», «устойчивость», «сколько нужно») и уже существующем сценарии — модели дополнительно подсказывается предпочтительный инструмент на этот конкретный ход.

Модель всё равно сама решает, какой инструмент вызвать — подсказки не подменяют её выбор, а повышают приоритет нужного варианта.

Форматирование ответов

Ответы ассистента рендерятся как Markdown — заголовки, списки, **жирный**/курсив, `код`, цитаты — вместо сырых спецсимволов. Когда ассистент вызывает Сценарий / Ансамбль / Доза-отклик / Чувствительность / Слабые сигналы, под текстом ответа появляется картинка соответствующего графика (плоское изображение, не интерактивный график — чтобы длинная сессия не становилась тяжёлой).

Трейс агента

Кнопка в верхней панели вкладки «Ассистент» открывает «Трейс агента» — сырую хронологию того, что модель реально получила и решила на каждом шаге текущей сессии: системный промпт, сработавшие жёсткие подсказки маршрутизации, необработанные шаги модели, результаты инструментов. Это не то, что отрисовано в чате — полезно, когда ответ выглядит странно и нужно понять, что именно увидела модель и почему выбрала тот или иной инструмент.

Экспертный режим

Прямое управление движком, пять панелей переключателем сверху: Сценарий, Ансамбли, Отклик, Чувствительность, Сигналы. Любой график разворачивается на весь экран по нажатию.

Переигровка сохранённого сценария (Источник)

В панелях «Чувствительность» и «Слабые сигналы» появилось поле «Источник» — можно выбрать «База» (чистый прогон) или любой уже посчитанный сценарий из истории (Сравнение / Ассистент). Тогда скрининг параметров или поиск слабых сигналов идёт не по чистой базовой линии, а по конкретному сценарию — например, «насколько чувствителен ВВП к параметрам именно при шоке энергоснабжения», а не вообще.

Как читать графики

Чувствительность (Морris, μ*)

Бары — не сырое значение μ*, а доля от самого влиятельного параметра (100% у лидера, 0–100% у остальных). μ* само по себе не имеет интуитивного масштаба — так нагляднее. 33 калиброванных параметра теперь участвуют в скрининге (раньше — только 7 из другого, несвязанного набора, из-за чего часть параметров всегда показывала ноль независимо от метрики).

Слабые сигналы

  • Аномалии Махаланобиса — совместное отклонение состояния от собственной истории; порог χ² на графике, аномальные шаги — красные точки.
  • Структурные сдвиги — вероятность (Байес, BIC-штраф), что уровень метрики сместился; показаны только заметные (≥50%).
  • Критическое замедление — рост автокорреляции/дисперсии, предвестник смены режима. Помечено как экспериментальное: на одиночной детерминированной траектории тренд может отражать сам сценарий, а не настоящее замедление — полноценно метод работает только на стохастическом ансамбле.

Советы и устранение проблем

  • Если ответ ассистента выглядит нерелевантным — откройте «Трейс агента» и посмотрите, какой инструмент реально был вызван и что подсказала маршрутизация.
  • Сессии сохраняются на диск автоматически — можно закрыть приложение и вернуться позже.
  • Для аналитических вопросов («почему», «что если», «насколько чувствительно») лучше всего подходят модели с надёжной поддержкой function calling (DeepSeek-chat, GPT-4o-mini, Qwen2.5 через Ollama).
  • «Слабые сигналы» по умолчанию считаются на 20 годах (не меньше 12) — на слишком коротком горизонте тренд критического замедления статистически ненадёжен.
