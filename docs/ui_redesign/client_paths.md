# GIM18 — клиентские пути (user journeys)

Сопутствует [`design_spec.md`](design_spec.md). Каждый путь: шаги ЛПР → экраны → что под капотом → крайние случаи → критерий успеха.

Обозначения: 🟦 ведущий путь · ⬜ вторичный · `code` — реальная команда/артефакт.

---

## Путь A 🟦 — «Играть за страну» (флагман, LLM-персона)

Сценарий-эталон: *«Сыграть за США в духе ястреба-протекциониста против Китая по торговле, без военной эскалации, горизонт 5 лет».*

**Шаги**
1. **Главная** → карточка «Играть за страну».
2. **Setup · За кого** → выбор страны (флаг-чипы + поиск). → `США`.
3. **Setup · Персона** → галерея архетипов. → `Ястреб-протекционист`.
4. **Доктрина-превью** (read-only) показывает «база → сдвиг» по 9 измерениям: ЛПР видит, *как* персона смещает поведение (эскалация ▲.17, открытость торговли ▼.23 …).
5. **Установочная декларация** — при желании правит 1–2 фразы (это и есть рычаг смещения). Advanced скрыт.
6. **Цель и горизонт** → цель одной фразой; горизонт-чип `5 лет`; остальные 12 стран = ИИ-автопилот.
7. **Запустить прогон** → экран **Прогон**: человеко-читаемые фазы (`baseline → внешняя политика → санкции → ресурсы → экономика → миграция → сверка → кредит`), прогресс-бар, лента **задекларированных позиций** ИИ-акторов.
8. **Ситуационная комната**: вердикт + критичность → прогноз исходов → траектории (policy vs baseline) → драйверы → «Что дальше».
9. **Что дальше**: `Сравнить с «Голубем»` · `Изменить ход` · `Экспорт брифинга`.

**Под капотом**
```
gim hybrid --tables "United States" \
  --intent "United States=Дожать Китай по торговле, без военной эскалации" \
  --round-years 5 --background-policy compiled-llm --dashboard --brief
```
+ persona-bias (архетип + декларация) инъецируется в контекст компиляции доктрины (`CompiledLLMPolicyManager`). Превью «база→сдвиг» = двойная компиляция. Итог: `run_manifest.json → evaluation.json / hybrid_result.json / decision_brief.md`.

**Крайние случаи**
- Нет `DEEPSEEK_API_KEY` → персона-смещение/фон деградируют до эвристической доктрины (`_heuristic_doctrine`); UI честно помечает «эвристический режим», прогон не падает.
- Двойная компиляция дорогая → показать базовую доктрину сразу, сдвиг дорисовать асинхронно (или эвристический предпросмотр).
- Персона не различима в исходах → флаг калибровки (см. ограничения spec §7).

**Критерий успеха:** ЛПР доходит от Главной до вердикта ≤ 4 решений; понимает, *что* делает персона, не открывая Advanced.

## Путь B 🟦 — «Что если…» (пресет-шоки)

Сценарий: *«Что если Иран закроет Ормузский пролив?»*

**Шаги**
1. **Главная** → «Что если…».
2. **Карта/сетка пресет-шоков** — карточки: `Ормуз закрыт`, `Блокада Тайваня`, `Санкционная спираль`, `Кибер-сбой`, `Торговая война`, `Региональное давление` (= шаблоны `scenario_library`).
3. **…или свой вопрос** — свободное поле «задайте свой сценарий» (например «как выход США из НАТО скажется на…»). Выбор пресета и свободный вопрос взаимоисключающи: ввод текста снимает выделение пресета.
4. Одна ручка **интенсивности** (мягкий/жёсткий) + горизонт-чип. Без прочих настроек.
5. **Запустить** → Прогон → **Ситуационная комната** (тот же результат-экран, что и в A).

**Под капотом**
```
# пресет:
gim question --template <preset> --actors <auto> --sim --dashboard --brief
# свой вопрос:
gim question --question "<free text>" --sim --dashboard --brief
```
Пустой шаблон / свободный вопрос → авто-детект акторов и шаблона моделью (как сейчас). Итог: `evaluation.json / decision_brief.md`.

**Крайние случаи:** пресет без явных акторов → авто-резолв из описания; интенсивность вне диапазона → клампинг.

**Критерий успеха:** результат за 1–2 клика от Главной; ЛПР не видит ни одного флага рантайма.

## Путь C ⬜ — «Сравнить» (стратегии/персоны)

Сценарий: *«Ястреб против Голубя за США — где риск ниже?»*

**Шаги**
1. Из Ситуационной комнаты `Сравнить с «…»` **или** Главная → «Сравнить».
2. Выбор 2–3 прогонов (персоны/политики одной страны или сохранённые сценарии).
3. **Экран сравнения**: колонки рядом — вердикты, кольца критичности, прогноз исходов (diff-полосы), ключевые расхождения драйверов.

**Под капотом:** 2–3 прогона путей A/B + diff `evaluation.json` (`risk_probabilities`, `criticality_score`, `driver_scores`). Прогоны — объекты первого класса (принцип 9): сохраняются и переоткрываются.

**Критерий успеха:** видно одно главное расхождение исходов без чтения сырых JSON.

## Путь D ⬜ — «Экспертный режим» (сохранение текущего пульта)

Полный нынешний билдер (`question / game / hybrid` со всеми флагами, CSV состояний, `state_year`, `max_countries`, `llm_refresh*`, бинарные флаги). Для аналитика/себя, спрятан за отдельной дверью. **Ничего из текущих возможностей не теряется** — это страховка прогрессивного раскрытия.

---

## Сквозные правила (во всех путях)

- **Baseline везде:** графики и доктрина — «текущее против базы» (данные уже есть: baseline+policy в `evaluation.json`).
- **Задекларированная позиция:** ИИ-акторы объявляют ход перед действием (лента в Прогоне; данные — `hybrid_result.json` + action CSV).
- **Трейс-строка:** на каждом экране приглушённо — точная команда/путь артефакта (честность + воспроизводимость; ценит исследователь).
- **Деградация без LLM:** любой путь работает на эвристиках, UI это помечает.
- **Двуязычность:** RU primary / EN switch; технические артефакты (CSV, имена шаблонов) остаются как есть под капотом.
- **Экспорт брифинга:** `decision_brief.md` → читаемый PDF/MD из Ситуационной комнаты.
