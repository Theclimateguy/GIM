# GIM19: план улучшения уравнений и замыкания модели

Составлен 2026-08-04 по итогам 20-летнего прогона (results/forward20/): экономика
стабильна и нетривиальна, социальный контур бистабилен (военный импульс 2024–26
сталкивает RUS в высоконапряжённый аттрактор без возврата). Два трека: надёжность
уравнений и замыкание петель.

**Статус 2026-08-04 (вечерняя сессия): P1 закрыты — B7, A1+A2, A3, B1, B2.**
Итоги: гибридный пер-уравненческий фит по OOS (квартальные regulator/executive/
inflation, годовые остальные; принцип Тейлора — warning, не constraint: его
enforcement стоил OOS 2.39→3.09); holdout-2026 по ставке +32%→+12%; мирные
восстанавливающие силы (κ_a=0.42 к базе 0.39, доверие +0.95пп за 1% роста
доходов) сделали гистерезис конечным (возврат ~8 лет мира в 20-летнем прогоне);
бифуркационная карта: возврат везде ≤14 лет, граница медленного возврата на
длительности импульса ~5–6 лет. Осталось по трекам: A6 (ждёт данных по другим странам) (B3 закрыта вечером: блочная π замещает Phillips для RUS; реализм инфляции сдвинул режимный кризис ядра с 2030 на 2027).

## Трек A — методы оценки (сейчас: OLS на 9–10 годовых точках)

### A1. Квартальный рефит (P1, первый шаг) — ✅ 2026-08-04
Перевести фит всех уравнений с годовых на квартальные данные: 10 точек → 40–44.
Данные уже на диске (ставка/курс дневные, бюджет квартальный с декумуляцией,
доходы квартальные); докачать месячный ИПЦ (ЕМИСС id 31074 — большой, качать с
фильтром или помесячные годовые срезы). Сезонность бюджета уже разложена
(step_quarterly профили). Ре-спецификация лагов под квартал (инерция ставки
станет ~0.9 квартальная и т.п.).
Выход: `fit_block_dynamics.py --freq q`, golden-коридоры пересчитать осознанно.

### A2. Ограничения знаков/диапазонов (P1) — ✅ 2026-08-04
Constrained least squares (scipy.optimize.lsq_linear с bounds):
- pass-through девальвации ≥ 0; инерция ставки ∈ (0, 1); принцип Тейлора:
  коэффициент при инфляции в долгосрочке > 1 (проверять const/(1−lag));
- эластичность ренты ∈ [0.5, 1.2]; военные члены ≥ 0.
Лечит перевороты знаков при мультиколлинеарности (ловили дважды: pass-through,
rent_contraction).

### A3. Out-of-sample отбор спецификаций (P1) — ✅ 2026-08-04 (+ golden OOS-панель: test_block_oos_golden)
Rolling leave-future-out: фит на [2015..T], прогноз T+1, скольжение; критерий —
OOS RMSE, не r². Встроить в fit-скрипт как отчёт; golden-бэктест дополнить
OOS-панелью. Holdout-2026 уже есть — формализовать.

### A4. Регуляризация + Байес (P2) — ✅ 2026-08-04
Ridge/elastic net как быстрый вариант; целевой — байесовская оценка с
информативными приорами (pass-through РФ ~0.05–0.1 по оценкам ЦБ; приоры на
инерцию, эластичности из литературы). Бонус: credible intervals → веерные
траектории (fan_charts.py в ядре уже есть). Инструмент: аналитический
conjugate-ridge достаточно, PyMC не обязателен.

### A5. SUR / системная оценка (P2) — ❌ 2026-08-04, проверено и отвергнуто
Ошибки уравнений коррелированы (общие шоки — нефть, война): SUR повышает
эффективность. Альтернатива-максимум: малый BVAR с Minnesota-прайором.
**Итог эксперимента (scripts/sur_experiment.py):** корреляции подтверждены
(regulator↔inflation 0.53), но constrained-FGLS ухудшает OOS именно там, где
корреляция сильнее всего: ставка 2.39→2.67, инфляция 3.72→4.58 (шумная Σ на
малой выборке перераспределяет дисперсию против прогноза, зануляет π-отклик
и pass-through). Выигрыш executive −6% — в пределах шума. Не принято;
продакшен остаётся пер-уравненческим constrained hybrid.

### A6. Иерархический пул по 57 агентам (P3, стратегический)
Тейлор/Филлипс/pass-through оценить панельно: коэффициент страны = глобальное
среднее + случайное отклонение (partial pooling). Русские 10 точек
дисциплинируются панелью из сотен страно-лет. Это же — путь генерализации
блочных моделей на другие страны без 57 отдельных фитов. Данные: IMF IFS/BIS
policy rates, WDI inflation — качается по образцу текущих инжестов.

## Трек B — замыкание модели

### B1. Восстановление доверия и mean-reversion напряжённости (P1, главное) — ✅ 2026-08-04
Сейчас канал только толкает вниз: trust зеркалит Δtension, в мирное время
лечиться нечем → гистерезис абсолютный. Сделать:
- trust ← β⁺·(реальный рост доходов) в мирном режиме; фит на Леваде 2016–2019
  (одобрение реально отрастало после 2015);
- mean-reversion: Δtension += κ·(tension_base − tension), κ и база — из мирного
  подокна Левады; W-режим отключает reversion (война держит);
- перегнать 20-летний прогон: гистерезис должен стать конечным (возврат за N лет),
  N — диагностика.

### B2. Бифуркационная карта (P1, диагностика) — ✅ 2026-08-04
Свип по силе/длительности военного импульса → граница возврат/невозврат
социального контура. Скрипт + картинка. Это превращает вчерашнюю находку
в измеримое свойство модели.

### B3. Унификация инфляции RUS (P2) — ✅ 2026-08-04
Две параллельные инфляции: блочная (мост) и ядровая (Phillips). Для RUS блочная
должна замещать ядровую (как уже сделано со ставкой через _block_policy_rate) —
иначе расходятся. Точка врезки: update_inflation_unemployment, тот же паттерн
getattr-override, флаг-гейт, бит-в-бит тест.

### B4. Рента → капитал/отток (P2) — ✅ 2026-08-04
oilgas_rev блока сейчас влияет только на tension. Замкнуть: доля ренты →
инвестиции ядра (accum капитала RUS) и/или отток (санкционный режим). Малый
коэффициент, фит по инвестданным Росстата (капвложения ТЭК — ЕМИСС).

### B5. Проверить силу канала ставка → экономика ядра (P2) — ✅ 2026-08-04
_block_policy_rate входит в compute_effective_interest_rate — прогнать
чувствительность: ставка 7% vs 20% должна видимо давить инвестиции/ВВП RUS.
Если канал слабый — усилить (кредитный канал ядра).

### B6. Подключить лежащие данные (P2) — ✅ 2026-08-04 (долг регионов — хвост данных)
- Левада по институтам (скачано, 6 сущностей) → дифференциация trust по блокам:
  доверие президенту/правительству → executive, армии (докачать) → security.
- NGFS-климат 83 регионов → EXPOSURE в households (labour_productivity_loss
  юга → региональные доходы → агрегвойна households).
- Региональные бюджеты 85×2017–2021 → STRUCTURAL-трансферты в executive
  (top-down split §7.2) + региональный долг.

### B7. Golden на интегрированный прогон (P1, дёшево) — ✅ 2026-08-04
5-летний снапшот траектории ядро+блоки (RUS gdp/tension/trust/ставка) в
golden-коридоры — сейчас стыковку никто не охраняет от регрессий.

### B8. Ансамбль/веера (P3) — ✅ 2026-08-04
